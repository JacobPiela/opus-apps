
# Hex Manager

This is a stript down version for opusOS the original can be found [hear](https://github.com/nielsvoss/hexmanager)

cloud features have been remove and the patterns database minified

focal port no longer needs to be on right side

Hex Manager offers a simple programming language to write Hex casting spells.

A list of patterns for Hex Casting and some of its addons is found in this spreadsheet:
https://object-object.github.io/HexBug/patterns.csv.
More information about the programming language can be found [hear](https://github.com/nielsvoss/hexmanager)
