# Data files

- `patterns.csv`: Contains a list of HexCasting patterns. From https://object-object.github.io/HexBug/patterns.csv

# How to convert

- Remove all columes exept translation,direction,pattern,is_great,name
- Remove top row
- Convert directions to any of E,NE,NW,W,SW,SE
- Replace is_great true and false with 1 and 0
